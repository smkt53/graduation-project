# graduation-project
卒業研究制作
APIを含めたコーディングが複雑であることからそのサポートをするソフトウェアを開発する。
APIの提供団体によって仕様が異なることからGemini apiを用いて柔軟に対応できるようにする。

試用段階では複数回試すため、バージョンは次に設定してある。
version: gemini-3.8-flash
最新版のgemini-4.0-argonも存在するが、無料枠のリソース範囲内で多く試すためである。

簡単なトーク
1レスポンス200トークン
1日65536トークン

対話型システムを検討しているが、生成できる文字数に制限があることから、以下を最低限の目標とする。
＊手順の提示
＊コード生成（修正）
＊サンプルコードの提示
